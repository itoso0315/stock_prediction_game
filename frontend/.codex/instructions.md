

# Codex Instructions

## 役割

あなたはこのプロジェクトの実装担当です。
仕様書（TASKS/Task_xxx.md）に従って実装してください。

## 基本ルール

- TASKS/Task_xxx.md を唯一の仕様書として扱う
- 仕様書に書かれていない機能は追加しない
- 推測で仕様を補わない
- 変更対象外のファイルは編集しない
- 大きな設計変更は行わない

## 実装品質

実装後は必ず以下を実行すること。

- dart format .
- flutter analyze
- flutter test
- git diff --check

エラーがある場合は修正してから完了報告する。

## 完了報告

必ず以下を報告すること。

1. 変更したファイル
2. 実装内容
3. flutter analyze の結果
4. flutter test の結果
5. 残課題

## 禁止事項

- 外部パッケージを勝手に追加しない
- Python側を変更しない（Taskで許可された場合を除く）
- 仕様外のUI・機能を追加しない
- 動作未確認のまま完了と報告しない
