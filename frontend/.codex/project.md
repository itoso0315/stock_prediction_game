

# Project Overview

## プロジェクト名

Stock Prediction Game

## 目的

株価チャートを見て将来の値動きを予測するゲームを開発する。

ゲームを通じて、テクニカル分析・チャートの読み方・投資判断力を楽しく学べるアプリを目指す。

## システム構成

### Flutter（frontend）

- UI
- 画面遷移
- ゲーム画面
- ユーザー操作

### Python

- 問題生成
- チャート画像生成
- データ取得
- 将来的なAPI

## 開発方針

- Task駆動開発を採用する
- TASKS/Task_xxx.md を仕様書とする
- 小さなTask単位で実装する
- ChatGPTが設計・レビューを担当する
- Codexが実装を担当する

## 最終目標

Flutter・Python・FastAPIを組み合わせ、スマートフォンでも遊べる株式学習ゲームを完成させる。
