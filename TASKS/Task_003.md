# TASK 003 - 日経225から3銘柄をランダムに選択する

## 1. 目的

Stock Trainerで毎回異なる問題を出題するための第一歩として、
日経225採用銘柄から重複しない3銘柄をランダムに選択する仕組みを実装する。

Task 002では固定した3銘柄を使用していた。

Task 003では固定銘柄を廃止し、選択された3銘柄を
`Chart A / Chart B / Chart C` として画面に表示する。

このTaskでは、3銘柄の表示期間を厳密に揃える処理や、
将来の騰落率計算、回答機能は実装しない。

---

## 2. ゴール

Streamlitを起動するたびに、日経225採用銘柄から
重複しない3銘柄がランダムに選択されること。

選択された銘柄は内部では保持するが、利用者の画面には表示しない。

画面には次の形式でローソク足チャートを縦に表示する。

```text
Stock Trainer

Chart A
［ランダムに選択された銘柄のローソク足チャート］

Chart B
［ランダムに選択された銘柄のローソク足チャート］

Chart C
［ランダムに選択された銘柄のローソク足チャート］
```

---

## 3. 実装内容

### 3.1 日経225銘柄一覧

次のファイルを新規作成する。

```text
data/nikkei225.py
```

現在の日経225採用銘柄の証券コードを、静的なタプルとして管理する。

公開する定数：

```python
NIKKEI_225_TICKERS: tuple[str, ...]
```

証券コードはYahoo Financeの `.T` を付けず、
4文字の証券コード文字列で管理する。

数字のみのコードに加えて、`285A` や `543A` のように
英字を含む証券コードも許可する。

例：

```python
NIKKEI_225_TICKERS = (
    "1332",
    "1605",
    "285A",
)
```

要件：

- 日経225の公式構成銘柄一覧を参照する
- 実装時点の公式構成銘柄を人手で静的に登録する
- 225銘柄を重複なく収録する
- 証券コードは4文字の証券コード文字列とする
- 数字のみのコードに加えて、英字を含む証券コードも許可する
- 会社名はこの定数に含めなくてよい
- ファイル内に一覧の参照元と更新確認日をコメントで残す
- 実行時に外部Webページへアクセスして構成銘柄一覧を取得してはならない

日経225の構成銘柄は将来変更される可能性があるため、
静的スナップショットとして管理する。

---

### 3.2 ランダム選択処理

日経225銘柄一覧から重複しない3銘柄を選択する関数を実装する。

配置場所は次のいずれかとする。

```text
game/question_generator.py
```

推奨する公開API：

```python
def select_random_tickers(
    tickers: tuple[str, ...],
    count: int = 3,
    rng: random.Random | None = None,
) -> tuple[str, ...]:
    ...
```

要件：

- 戻り値はタプルとする
- 同じ銘柄を複数回選択しない
- 元の銘柄一覧を書き換えない
- `random.Random` を渡すと同じ結果を再現できる
- `rng=None` の場合は通常のランダム選択を行う
- 選択数が0以下の場合は `ValueError`
- 銘柄一覧より多い数を要求した場合は `ValueError`
- 型ヒントとDocstringを付ける

---

### 3.3 app.pyへの組み込み

Task 002で使用していた固定3銘柄を削除する。

Task 003で実装したランダム選択処理を利用し、
日経225から3銘柄を選択する。

選択された銘柄とチャートラベルを次の順番で対応させる。

```text
1つ目 → Chart A
2つ目 → Chart B
3つ目 → Chart C
```

既存の `download_daily_prices()` を利用して株価を取得する。

既存の `create_candlestick_chart()` を利用してチャートを生成する。

画面表示順は次のとおりとする。

```text
Chart A
Chart B
Chart C
```

---

### 3.4 画面に表示しない情報

問題画面には、次の情報を表示しない。

- 会社名
- 証券コード
- Yahoo Financeのティッカー
- 業種
- 日経225の銘柄一覧
- 将来の騰落率
- 正解に関する情報

チャートタイトルは以下のみとする。

```text
Chart A
Chart B
Chart C
```

---

### 3.5 データ取得失敗時の処理

選択された銘柄の株価データ取得に失敗した場合、
アプリ全体をクラッシュさせない。

通常画面には次のメッセージだけを表示する。

```text
チャートを表示できませんでした。時間をおいて再度お試しください。
```

例外の詳細、会社名、証券コード、ティッカーは
通常の利用者画面へ表示しない。

Task 003では、取得に失敗した銘柄を別の銘柄へ
自動的に差し替える処理までは実装しない。

### 3.6 補足仕様

Task003では、Streamlitの再実行時に出題銘柄が変更されてもよい。

同一問題の保持はTask004で `st.session_state` を導入して対応する。
