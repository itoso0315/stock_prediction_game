# TASK 004 - 共通60営業日と出来高を表示する

## 1. Taskの目的

3銘柄のローソク足チャートと出来高を、同じ開始日・同じ終了日・同じ60営業日で表示できるようにする。

Task003では各銘柄をランダムに選択したが、表示期間は銘柄ごとに揃っていなかった。
Task004では、3銘柄すべてで利用できる共通取引日から同一の60営業日を切り出し、比較可能なローソク足・出来高チャートとして表示する。

---

## 2. 実装対象

- ランダムに選択された3銘柄を対象とする
- 各銘柄の株価データは `period="5y"` で取得する
- 3銘柄すべてで利用可能な共通取引日を求める
- 共通取引日から同一の60営業日をランダムに切り出す
- 各ローソク足チャートの下部に、同じ60営業日の出来高を棒グラフで表示する
- ローソク足と出来高は同じX軸を共有する
- 土日・祝日など取引のない日をX軸上に空白として表示しない
- Chart A / Chart B / Chart C の表示方法は維持する
- 会社名・証券コード・ティッカー・将来情報は表示しない
- 取得・共通期間抽出・チャート生成のいずれかに失敗した場合は、部分表示せず利用者向けエラーメッセージだけを表示する
- 型ヒントとDocstringを維持する

---

## 3. 共通取引日の定義

共通取引日は、3銘柄のDataFrameの日付インデックスの積集合とする。

実装時は以下を満たすこと。

- インデックスは `pd.to_datetime(..., errors="raise")` で日付へ変換し、変換不能な値がある場合は `ValueError` とする
- 日付変換後のインデックスに `NaT` が1件でも含まれる場合は `ValueError` とする
- 日足データの現地日時を維持したままタイムゾーン情報だけを除去する（UTCへの変換は行わない）
- 時刻部分は日付単位へ正規化する
- 重複日付がある場合は最後の行を残す（`keep="last"`）
- 日付インデックスを昇順に並べる
- 入力DataFrameそのものは変更しない

取引停止などで一部銘柄に存在しない日付は、共通取引日には含めない。

---

## 4. 共通期間抽出API

`game/question_generator.py` に、3銘柄の共通60営業日を抽出する公開関数を追加する。

推奨API：

```python
def select_common_window(
    price_frames: tuple[pd.DataFrame, ...],
    window_size: int = DISPLAY_TRADING_DAYS,
    rng: random.Random | None = None,
) -> tuple[pd.DataFrame, ...]:
    ...
```

要件：

- 3つ以上ではなく、Task004では3銘柄分のDataFrameを受け取る
- 戻り値は入力順と同じ順番のDataFrameタプルとする
- 3つの戻り値は完全に同じ日付インデックスを持つ
- 各DataFrameは `window_size` 件を持つ
- 元のDataFrameを変更しない
- この関数は日付インデックスと件数だけを検証し、OHLCV列の検証はチャート生成層で行う
- `random.Random` を受け取れる
- 同じ乱数シードでは同じ期間を返す
- `rng=None` の場合はPython標準のモジュールレベル `random` を使用して通常のランダム選択を行う
- `window_size` が0以下の場合は `ValueError`
- DataFrameが3件でない場合は `ValueError`
- 空のDataFrameを含む場合は `ValueError`
- 正規化後の日付インデックスに `NaT` が含まれる場合は `ValueError`
- 共通取引日が `window_size` 未満の場合は `ValueError`
- 共通取引日がちょうど `window_size` 件の場合は全件を使用する
- 共通取引日が `window_size + 1` 件以上の場合は有効な開始位置からランダムに選択する
- 型ヒントとDocstringを付ける

既存の `DISPLAY_TRADING_DAYS = 60` を再利用し、新たに同じ意味の定数を重複定義しない。

## 5. チャート生成

`ui/charts.py` の既存公開APIを不必要に壊さず、ローソク足と出来高を1つのPlotly Figureとして生成できるように拡張する。

既存API：

```python
create_candlestick_chart(
    prices: pd.DataFrame,
    title: str = "Chart A",
) -> go.Figure
```

要件：

- 関数名・引数・戻り値 `go.Figure` を維持する
- 関数シグネチャと戻り値は維持するが、Task004以降は `Volume` 列を追加の必須入力とする。この入力要件の変更は許容する
- 上段にローソク足を表示する
- 下段に出来高の棒グラフを表示する
- 上下段でX軸を共有する
- 入力DataFrameには `Open / High / Low / Close / Volume` を必須とする
- `Volume` 列がない場合は `ValueError`
- Task004では出来高を常に表示する
- Plotlyのレンジスライダーは非表示とする
- 選択した60共通日の最小日から最大日までの暦日のうち、共通日付に含まれないすべての日を非取引日として扱い、Plotlyの `rangebreaks` 等でX軸上の空白を詰めて表示する
- ローソク足と出来高のX軸の日付が完全に一致する
- 出来高以外のテクニカル指標は追加しない
- 上下段の高さ比率、色、凡例などの細かな見た目は実装者判断でよい

## 6. app.pyへの組み込み

`app.py` では以下の順序で処理する。

1. 日経225から3銘柄を選択する
2. 3銘柄すべての株価データを `period="5y"` で取得する
3. 3件すべての取得成功を確認する
4. `select_common_window()` で共通60営業日を抽出する
5. 3つのFigureをすべて生成する
6. すべて成功してから Chart A / Chart B / Chart C を縦方向に表示する

途中で失敗した場合は、それまで生成済みのチャートを部分表示しない。

通常画面に表示するエラーメッセージ：

```text
チャートを表示できませんでした。時間をおいて再度お試しください。
```

例外詳細、会社名、証券コード、ティッカーは通常画面へ表示しない。

## 12. 動作確認

1. 3つのDataFrameが60件であること
2. 3つのDataFrameの日付インデックスが完全一致すること
3. 59共通日では `ValueError` となること
4. ちょうど60共通日では全件が選択されること
5. 61件以上ではランダムな開始位置が選ばれること
6. 同一シードで同じ期間になること
7. 異なるシードで異なる期間になり得ること
8. 入力DataFrameが変更されないこと
9. 日付インデックスに `NaT` が含まれる場合は `ValueError` となること
10. ローソク足と出来高が同じ60営業日を使用すること
11. 選択期間内で共通日付に含まれないすべての暦日がX軸上の空白として表示されないこと
12. `Volume` 列不足時に `ValueError` となること
13. チャートが縦方向に表示されること
14. 銘柄情報が表示されないこと
15. 取得または生成失敗時に部分表示されないこと
16. 共通期間を作れない場合に利用者向けメッセージが表示されること
17. 既存公開APIが維持されていること
18. Streamlitが正常起動すること
