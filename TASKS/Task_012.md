# Task 012

## タイトル
結果画面で観察期間と予測結果を1つの連続チャートとして表示する

---

## 1. 目的

結果画面を見た利用者が、問題画面でどこまでのチャートを見て予測し、その先の20共通取引日で実際にどう値動きしたのかを、一目で理解できるようにする。

現在の結果画面では、問題画面で表示した120共通取引日のチャートと、回答後に表示する20共通取引日の将来チャートが別々に表示されているため、利用者にとって次の関係が分かりにくい。

- どこまでが問題画面で見えていた期間か
- どこから先が予測対象だった期間か
- 問題画面の最後のローソク足と、結果画面の最初のローソク足がどのようにつながっているか
- 予測時点から1か月後まで、価格がどのように推移したか

Task012では、観察期間120共通取引日と予測結果期間20共通取引日を1つの連続チャートへ結合し、予測対象期間を視覚的に区別する。

---

## 2. ゴール

結果画面で各Chart A/B/Cについて、次の流れを直感的に理解できるようにする。

```text
問題画面で見えていた120共通取引日
                    ↓ 基準日
その先に実際に動いた20共通取引日
```

利用者が結果画面を見た瞬間に、次の2点が理解できることをゴールとする。

- 「ここまでの情報を見て予測した」
- 「その先は実際にこう動いた」

## 7. 入力データの検証

`create_review_chart()`は次を検証する。

### 必須列

`display_data`と`future_data`の両方に、次の列が必要である。

- `Open`
- `High`
- `Low`
- `Close`
- `Volume`

不足している場合は`ValueError`とする。

### 件数

- `display_data`は120件であること
- `future_data`は20件であること

件数が異なる場合は`ValueError`とする。

### 日付

- 両方のインデックスが日付として扱えること
- 両方のインデックスが昇順であること
- 重複日付がないこと
- `display_data.index[-1] == base_date`であること
- `future_data.index[0] > base_date`であること
- `display_data`と`future_data`の日付が重複していないこと
- 連結後の日付が昇順であること
- 連結後が140件であること

### 入力非破壊

- `display_data`を変更しない
- `future_data`を変更しない
- 連結処理ではコピーを使用する

## 9. 観察期間と予測期間の視覚表現

### 9.1 将来期間の背景

予測対象期間である`future_data`の20共通取引日だけを、薄いグレー背景で表示する。

- 観察期間120共通取引日には背景色を付けない
- 将来20共通取引日のみ背景色を付ける
- 背景色はローソク足と出来高の両方へ適用する
- 背景色はローソク足や出来高が読める程度の薄さにする

Plotlyの`add_vrect()`または同等の方法を使用する。

背景範囲のX座標は次の式で算出する。

```python
boundary_x = display_data.index[-1] + (
    future_data.index[0] - display_data.index[-1]
) / 2

future_last_half_width = (
    future_data.index[-1] - future_data.index[-2]
) / 2

background_x0 = boundary_x
background_x1 = future_data.index[-1] + future_last_half_width
```

- `background_x0`は観察期間最終日と将来期間初日の中間位置とする
- `background_x1`は将来期間最終日の次方向へ、直前の将来取引日との間隔の半分だけ延長する
- 将来20共通取引日の最初と最後のローソク足・出来高バーを背景内へ完全に含める
- 観察期間最終日のローソク足・出来高バーへ背景をかけない

背景スタイルは次の固定値とする。

```python
fillcolor = "lightgray"
opacity = 0.15
layer = "below"
```

### 9.2 基準日の境界線

観察期間と将来期間の境界へ垂直線を表示する。

境界線は基準日ローソク足の中央ではなく、観察期間最終日と将来期間初日の境界位置を示す位置へ表示する。

境界線のX座標は、背景開始位置と同じ次の値を使用する。

```python
boundary_x = display_data.index[-1] + (
    future_data.index[0] - display_data.index[-1]
) / 2
```

利用者が「ここまで見て予測し、この先が実際の値動き」であることを直感的に理解できることを目的とする。

- 線種：破線
- 色：グレー系
- ローソク足と出来高の両方へ適用

### 9.3 注釈

次の注釈を表示する。

観察期間側：

```text
ここまで見て予測
```

将来期間側：

```text
予測対象期間
```

注釈はチャートの値動きを隠さない位置へ配置する。

具体的には、Figure上部のpaper座標を使用して表示する。

- 「ここまで見て予測」：基準日境界線の少し左側
- 「予測対象期間」：将来20日区間の中央付近

注釈はローソク足の価格位置ではなく、Figure上端付近へ固定する。

注釈はFigure上端付近へ固定し、価格変動やローソク足・出来高と重ならない位置へ配置する。

利用者がチャートを読む妨げにならないことを優先し、注釈位置の細かな実装方法は実装側へ委ねる。

## 10. 非取引日の空白除去

連結後の140共通取引日の最小日から最大日まで、すべての暦日を生成する。

```python
calendar_dates = pd.date_range(
    start=combined_data.index.min(),
    end=combined_data.index.max(),
    freq="D",
)
```

実際の連結日付に含まれない暦日を求める。

```python
non_trading_dates = calendar_dates.difference(combined_data.index)
```

この日付を`rangebreaks`へ設定する。

これにより次の空白を除去する。

- 土曜日
- 日曜日
- 祝日
- 年末年始休場
- その他、共通取引日に含まれない日

ローソク足と出来高の両方へ同じ`rangebreaks`を適用する。
