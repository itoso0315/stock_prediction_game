# TASK 002 - 3つのチャートを画面に表示する

## 1. 目的

Stock Trainerの最初のプレイ画面として、3つの株価チャートを縦に表示する。

このTaskでは、ゲーム全体を完成させるのではなく、まず「3つのチャートが画面に並ぶ状態」を作る。

銘柄選択ロジック、共通期間の厳密な決定、回答、正誤判定、結果表示は後続Taskで実装する。

---

## 2. ゴール

Streamlitを起動すると、次の内容が表示されること。

```text
Stock Trainer

Chart A
［ローソク足チャート］

Chart B
［ローソク足チャート］

Chart C
［ローソク足チャート］
```

3つのチャートは縦方向に表示する。

---

## 3. 実装内容

### 3.1 表示用データ

Task 001で用意した株価データ取得処理を利用し、3つのチャート表示に必要な株価データを準備する。

このTaskでは、動作確認を優先するため、使用する3銘柄は固定でもよい。

例：

```python
TICKERS = (
    "7203.T",
    "8306.T",
    "9432.T",
)
```

使用する銘柄は会社名ではなく、Yahoo Finance形式のティッカーでコード内に指定する。

---

### 3.2 チャートタイトル

各チャートのタイトルは次のとおりとする。

```text
Chart A
Chart B
Chart C
```

画面には以下を表示しないこと。

- 会社名
- 証券コード
- Yahoo Financeのティッカー
- 将来の騰落率
- 正解に関する情報

---

### 3.3 チャート生成

`ui/charts.py` のチャート生成処理を利用または拡張し、タイトルを指定してローソク足チャートを生成できるようにする。

想定する公開API：

```python
create_candlestick_chart(
    prices: pd.DataFrame,
    title: str,
) -> go.Figure
```

既存APIを変更する場合は、Task 001の処理を不必要に壊さないこと。

Plotlyのレンジスライダーは非表示とする。

---

### 3.4 Streamlit画面

`app.py` を変更し、次の順番で表示する。

1. `Stock Trainer`
2. `Chart A`
3. `Chart B`
4. `Chart C`

Task 001で表示していた次の文言は削除する。

```text
準備中...
```

チャートは横並びではなく、縦方向に並べる。

---

### 3.5 エラー時の処理

株価データの取得またはチャート生成に失敗した場合は、アプリ全体をクラッシュさせず、Streamlit画面に次のメッセージを表示する。

```text
チャートを表示できませんでした。時間をおいて再度お試しください。
```

通常画面には、例外の詳細やティッカーをそのまま表示しないこと。
