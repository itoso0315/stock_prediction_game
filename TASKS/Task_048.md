

# Task 048: Chart Aに移動平均線のON/OFF表示を追加する

## 目的
Task047まででローソク足＋出来高を表示できるようになったChart Aに、MA20 / MA40 / MA70の移動平均線を追加する。

移動平均線は常時表示せず、ユーザーが必要なときだけON/OFFできるようにする。
初期状態はすべてOFFとし、チャートそのものを見て考えたあと、必要に応じて補助指標を表示できる投資学習体験にする。

## 現在地
- FlutterとFastAPIの連携は完了している。
- Chart Aにはyfinanceから取得した実在日本株の過去60営業日のOHLCが表示されている。
- Chart Aには同期間の実際の出来高も表示されている。
- 問題画面には基準日より未来のデータを表示しない。
- Chart Aカード全体をタップして回答候補として選択できる。
- Chart Aラベルは表示を維持する。
- Chart B/Cはまだプレースホルダー表示で、このTaskでは変更しない。
- 回答画面は後続Taskで本物の将来チャートへ刷新する予定であり、このTaskでは変更しない。

## 実装方針
まずChart Aを完成形に近づけてから、後続TaskでChart B/Cへ横展開する。

MA20 / MA40 / MA70は1つの「移動平均線表示」ボタンでまとめてON/OFFする。
初期状態はOFFとし、ON/OFF状態はQuestionを移動しても維持する。

切替ボタンは回答用Chartカードの外に配置し、操作時に回答選択が誤作動しないUIにする。

## 実装内容

### 1. Backendで移動平均線を計算する
- yfinanceから取得した実際の終値（Close）を利用する。
- MA20 / MA40 / MA70を計算する。
- 問題画面に表示する60営業日より前のデータも計算用として取得し、表示開始直後から可能な限りMAを描画できるようにする。
- MA計算に未来データを使用しない。
- 基準日より未来のMAを問題画面へ返さない。
- 日付順はcandlesと一致させる。

### 2. APIレスポンスへMAを含める
既存のAnswerデータ構造にある以下のフィールドを利用する。

- `ma20`
- `ma40`
- `ma70`

各MAは、Flutter側でローソク足の日付と対応付けられる形式で返す。
既存API契約を不必要に変更しない。

実装前に現在のモデル・sample JSON・テストを確認し、既存形式がある場合はそれを優先する。

### 3. Flutter側でMAデータを読み込む
- Answerまたは適切な既存モデルでMA20 / MA40 / MA70を保持する。
- APIから安全に読み込めるようにする。
- MAデータが空でも画面がクラッシュしない。
- 既存のOHLC・Volume読み込みを壊さない。

### 4. MA20 / MA40 / MA70をローソク足へ重ねて描画する
- 現在のローソク足チャート上へ移動平均線を重ねる。
- candlesと同じX軸位置を使用する。
- 出来高領域には描画しない。
- 3本を同時表示しても区別できる見た目にする。
- 既存のダークUIに馴染む視認性を確保する。
- 線を太くしすぎず、ローソク足の視認性を優先する。

### 5. 共通のON/OFF UIを追加する
回答用Chartカードの外に以下の切替を1つ追加する。

```text
移動平均線表示
```

要件：
- 初期状態はOFF。
- ONにするとMA20 / MA40 / MA70をまとめて表示する。
- OFFにすると3本をまとめて非表示にする。
- ON/OFFはデータを持つすべてのチャートへ即座に反映する。
- 選択状態が視覚的に分かる。
- UIは小さくシンプルにし、チャートを見る邪魔をしない。
- MA切替をタップした際にChart Aそのものの回答選択が意図せず切り替わらないようにする。

### 6. 問題が変わった場合の状態
- Questionが切り替わってもMA表示状態を維持する。
- 前の問題でONにした場合は次の問題でもON、OFFの場合はOFFのままとする。

### 7. テストを追加・更新する
少なくとも以下を確認する。

Backend：
- MA20 / MA40 / MA70を実データから計算できる。
- MA計算に基準日より未来のデータを使用しない。
- APIのChart AにMAデータが含まれる。
- candlesとの日付対応が正しい。

Flutter：
- MAデータをJSONから読み込める。
- 初期状態ではMAが非表示。
- 「移動平均線表示」をONにするとMA20 / MA40 / MA70が同時表示される。
- OFFにすると3本とも非表示になる。
- Question変更時にもON/OFF状態が維持される。
- MA切替操作で回答選択が誤作動しない。
- 既存の回答・Result遷移が壊れていない。
