

# TASK 010 - 予測期間を直感的に理解できるUIへ改善

## 1. 目的

利用者が問題画面・結果画面を通して、どこまでの情報を見て予測し、どこから先が未来だったのかを一目で理解できるようにする。

Task009で問題画面と結果画面は分離されたが、観察期間と結果期間の関係は依然として分かりづらい。

Task010ではゲームルールを視覚的に明確化し、予測体験を改善する。

## 5. 実装手順

1. 問題画面に観察期間を表示する（以降、観察期間＝問題画面に表示される期間）。
2. 表示開始日と基準日を表示する。
3. 「あなたが利用できる情報はここまでです。この先60営業日の値動きを予測してください。」を表示する。
4. 結果画面に基準日・評価日を表示する。
5. 「60営業日後（約3か月後）」を表示する。
6. 基準日終値・評価日終値・騰落率を比較形式で表示する。

---

## 6. 表示仕様

### 問題画面

- 観察期間（display_data.index[0] ～ base_date）を3つのチャートすべての上に一度だけ表示する（各チャートごとではなく共通で1回）。
- 観察期間は `display_data.index[0] ～ base_date` の形式で明示する。
- 問題画面では評価日・将来価格・将来騰落率・その他将来情報を一切表示しない。
- 説明文（既存）：
  - 「📈 あなたが利用できる情報はここまでです。この先60営業日の値動きを予測してください。」

### 結果画面

- 日付情報（基準日・評価日・「60営業日後（約3か月後）」）を画面上部に一度だけまとめて表示する。
- Chart A/B/Cごとに「基準日終値」「評価日終値」「騰落率」を比較形式で表示する。
- 既存の騰落率単独表示はこの比較ブロックに置き換え、騰落率の重複表示を避ける。
- 表示フォーマット:
  - 日付: YYYY-MM-DD
  - 価格: 3桁カンマ区切り、小数点以下2桁、末尾に「円」
  - 騰落率: 既存Task007と同じ（+/-、小数点2桁）
