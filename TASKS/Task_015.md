

# Task 015

## タイトル
結果画面で実際の銘柄名・証券コードを公開し、Yahoo!ファイナンスのチャートへリンクする

## 1. 目的

現在のゲームでは、問題画面・結果画面ともにChart A、Chart B、Chart Cという匿名ラベルだけを表示している。

問題中に企業名や証券コードを表示すると、企業イメージや知名度などの先入観がテクニカル判断へ混ざるため、問題画面では今後も匿名表示を維持する。

一方、回答後の結果画面では、実際にどの銘柄・どの期間の値動きだったのかを明かすことで、答え合わせの納得感を高める。

Task015では、結果画面に次を追加する。

- Chart A/B/Cに対応する実際の企業名
- 証券コード
- Yahoo!ファイナンスのチャートページへのリンク

本Taskの目的は企業研究やファンダメンタルズ分析ではなく、あくまでテクニカル分析ゲームの答え合わせを充実させることである。

## 6. 企業名・証券コードのデータ元

現在の問題生成では、3銘柄を固定または候補リストから選択し、tickerを使って株価データを取得している。

Task015では、既存の銘柄定義または問題生成時に利用しているticker情報から、企業名と証券コードを決定する。

Yahoo!ファイナンスや別APIへ企業名を問い合わせる処理は追加しない。

### 証券コード

日本株tickerが次の形式の場合、末尾の`.T`を除いた部分を証券コードとして使用する。

```text
7203.T → 7203
6758.T → 6758
```

### 企業名

企業名は、問題生成側で管理する既存の銘柄候補情報へ明示的に保持する。

企業名をtickerから推測しない。

企業名をyfinanceのレスポンスへ依存させない。

## 7. データモデル

`ChartQuestion`へ次のフィールドを追加する。

```python
company_name: str
security_code: str
```

### company_name

正式または一般的に使用される日本語企業名を保持する。

例：

```text
トヨタ自動車
ソニーグループ
三菱ＵＦＪフィナンシャル・グループ
```

### security_code

証券コードを文字列で保持する。

例：

```text
7203
6758
8306
```

数値型ではなく文字列型とする。

理由：

- 将来的なコード体系変更に対応しやすい
- 表示用データである
- 先頭ゼロがある場合にも保持できる

### 既存フィールド

次の既存フィールドは維持する。

- `label`
- `display_data`
- `future_data`
- `base_date`
- `evaluation_date`
- `base_close`
- `future_close`
- `future_return_percent`

`GameQuestion`のフィールドは変更しない。

## 8. 問題生成ロジック

問題生成時、各ChartQuestionに次を設定する。

- Chartラベル
- tickerに対応する企業名
- tickerから`.T`を除いた証券コード
- 既存の価格・日付・騰落率情報

Chart A/B/Cへの割り当て順は既存どおり維持する。

同一入力・同一シードの場合、次が再現されること。

- 選ばれる銘柄
- Chart A/B/Cの割り当て
- 観察期間
- 予測期間
- 正解
- 企業名
- 証券コード

### 企業名マッピング

企業名は、tickerと企業名を組にした明示的な定義から取得する。

概念例：

```python
STOCK_CANDIDATES = (
    ("7203.T", "トヨタ自動車"),
    ("6758.T", "ソニーグループ"),
    ("8306.T", "三菱ＵＦＪフィナンシャル・グループ"),
)
```

実際のコードでは、既存の銘柄候補定義と整合する形へ変更する。

企業名とtickerを別々の配列で管理しない。

組み合わせがずれないデータ構造を使用する。

## 9. Yahoo!ファイナンスのリンク

各銘柄のリンクは次の形式とする。

```text
https://finance.yahoo.co.jp/quote/{ticker}/chart
```

例：

```text
https://finance.yahoo.co.jp/quote/7203.T/chart
```

URL生成には、既存のtickerをそのまま使用する。

証券コードだけから`.T`を再構築しない。

### リンク文言

次の固定文言を使用する。

```text
Yahoo!ファイナンスでチャートを見る
```

企業情報を見る、ニュースを見る、決算を見る、などの文言は使用しない。

### 開き方

Streamlit標準のリンク機能を使用する。

JavaScriptは使用しない。

外部サイトは新しいタブまたはブラウザ標準動作で開く。
