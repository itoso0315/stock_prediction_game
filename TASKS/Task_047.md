

# Task 047: Chart Aに実データの出来高を表示する

## 目的
Task046で実データ化したChart Aに、同じ期間の実際の出来高（Volume）を追加し、ローソク足と出来高を組み合わせた株価チャートとして表示する。

## 現在地
- FlutterとFastAPIの連携は完了している。
- Chart Aにはyfinanceから取得した実在日本株の過去60営業日のOHLCが表示されている。
- 基準日より未来の株価は問題画面に含めない実装になっている。
- Chart B/Cはまだプレースホルダー表示。
- 出来高はまだFlutterへ渡しておらず、画面にも表示していない。
- 移動平均線は後続Taskで実装するため、このTaskでは扱わない。

## 実装方針
Chart B/Cへ展開する前に、まずChart Aを完成形に近づける。
Task047ではローソク足の下部に出来高を常時表示する。
既存のChart Aの選択・回答・画面遷移・デザインを壊さず、チャート描画部分だけを拡張する。

## 実装内容

### 1. BackendでVolumeを取得する
- Task046で使用しているyfinanceの取得処理を拡張し、OHLCに加えてVolumeを取得する。
- OHLCとVolumeは同じ60営業日・同じ日付順とする。
- 基準日より未来のVolumeも問題画面へ含めない。
- 取得失敗時の既存エラー処理方針を維持する。

### 2. APIレスポンスへVolumeを追加する
- 各candleに `volume` を追加する。
- 既存の `date / open / high / low / close` は変更しない。
- Flutter側との既存API契約をできるだけ維持し、必要最小限の拡張にする。
- Chart Aのみ実データ対象とし、Chart B/CはこのTaskでは変更しない。

想定形式：

```json
{
  "date": "2024-05-01",
  "open": 1000.0,
  "high": 1050.0,
  "low": 980.0,
  "close": 1030.0,
  "volume": 1234567
}
```

### 3. FlutterのCandleモデルへVolumeを追加する
- `Candle` にvolumeを追加する。
- JSONから安全に読み込めるようにする。
- 既存OHLCの読み込みを壊さない。

### 4. 出来高チャートを描画する
- 現在のCandlestickChartを拡張し、ローソク足の下側に出来高バーを表示する。
- 価格チャートと出来高チャートのX軸位置を完全に揃える。
- 1本のローソク足と、その日の出来高バーが同じX位置になるようにする。
- 出来高は各日のVolumeの相対的な大きさが視覚的に分かる高さで描画する。
- 既存のダークUIに馴染む表示にする。
- Chart Aカードからはみ出さないようにする。

### 5. Chart Aのラベル・選択UIを維持する
- `Chart A` のラベルは削除しない。
- Chart Aカード全体をタップして選択できる現在の仕様を維持する。
- 回答確定ボタンなど既存の回答UIは変更しない。

### 6. テストを追加・更新する
少なくとも以下を確認する。
- BackendがVolumeを取得・変換できる。
- APIのChart A candlesにvolumeが含まれる。
- 60営業日のOHLCとVolumeの日付・件数が一致する。
- 基準日より未来のVolumeが含まれない。
- FlutterのCandleがvolumeをJSONから読み込める。
- 既存のQuestion/Answer/結果画面のテストが壊れていない。

## UI仕様
Chart Aカード内は概ね以下の構成とする。

```text
┌──────────────────────────────┐
│                              │
│       ローソク足              │
│                              │
│──────────────────────────────│
│       出来高バー              │
│                              │
│          Chart A             │
└──────────────────────────────┘
```

- ローソク足を主表示とする。
- 出来高はローソク足より低い領域に表示する。
- 価格軸や出来高の数値ラベルは、このTaskでは追加しない。
- 日付ラベルも、このTaskでは必須としない。
